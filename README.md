# Knowledge Loop Agent

面向 Windows Obsidian 的个人知识 Agent。项目以 Vault 为事实来源，目标是安全完成：

> 资料入库 → 带来源问答 → 受规则约束的笔记沉淀 → `daily/<主题>.md` → 按需知识回顾

当前已完成安全权限、Markdown/附件来源检索、受控写入、按需知识回顾和联网问答的可用闭环。文本能力由 DeepSeek 提供，GLM 只处理 PDF/图片，Tavily 只检索网页。自动追加默认关闭，只有在用户单独开启开关并授予对应权限后才会执行。

完整规划见 [Obsidian-Agent-开发计划.md](./Obsidian-Agent-开发计划.md)。新维护者请先阅读 [项目接手指南.md](./项目接手指南.md)。

## 当前能力

- Obsidian 右侧 Agent 对话与命令面板入口：侧栏只保留会话、计划确认和固定在底部的输入框；索引、检索、联网、附件、格式修复等能力由 Agent 按需调用，不再分散成工具面板。
- 本地 `.env` 密钥：插件首次启用时会在其本地目录创建 `.env` 模板；填写 `DEEPSEEK_API_KEY`、`GLM_API_KEY`、`TAVILY_API_KEY` 后，后续启动自动加载，密钥不会进入插件 `data.json`、审计日志或 Vault 笔记。
- DeepSeek 和 GLM 的最小连通性测试。
- 请求超时提示。
- 可持久化的目录权限规则：初始状态允许整个 Vault 的读取、模型外发、附件索引、联网、Inbox 写入、知识体系笔记新建、Daily 追加、既有笔记修改及 Agent 会话/画像写入；用户可收窄任一范围。
- 敏感目录规则：用户填写敏感目录后，该目录仍可本地读取、检索和写入，但其内容不能发送给 DeepSeek 或 GLM，因此也不会进入附件解析或本地知识问答请求。
- 仅记录行动元数据的审计轨迹；不记录笔记正文或 API Key。
- 可手动重建的 Markdown 本地索引与来源片段检索；仅处理已授权的文件夹。
- 基于来源的 DeepSeek 问答：逐片段检查模型外发权限，只发送允许的内容，并在回答中要求 `[S数字]` 来源标注。
- 受控写入：Inbox 新建和 `daily/<主题>.md` 追加复用同一行动提案、权限、预览、冲突检测与审计管线；必须先预览并明确确认。同名 Inbox 笔记自动使用 `-2`、`-3` 后缀，绝不覆盖原笔记。
- 结构化 Agent 提案：可将一份带来源的回答请求 DeepSeek 整理为 JSON 笔记草稿；模型不能指定文件路径或来源，插件会重新检查外发和写入权限后才显示预览。
- 知识体系整合：可从当前笔记、本地搜索结果或指定文件夹生成知识地图；再按需展开一个节点。地图阶段仅发送标题与短摘要，节点阶段才发送相关片段；模型返回的来源 ID 由插件校验。所有结果只能在 `知识体系/Agent/`（可配置）中新建，经预览确认后写入，绝不修改原始笔记。
- 知识库维护分析：用户输入维护目标后，Agent 检索相关 Markdown 笔记并输出有真实来源的重叠、冲突、缺口和过时项。它不创建第二套任务状态；如需生成知识地图或新笔记，由外层 Agent 继续安排现有工具，写入仍必须经过预览确认。
- 语义化 Agent 工具体系：模型只能组合索引、研究、知识整合、笔记、编辑器和系统诊断六类白名单工具，每次至多四步、至多重新规划一次；运行状态和每步结果可持久化，所有工具继续复用原有权限、预算、审计和写入预览管线。计划、执行确认和写入预览都以对话内卡片呈现，Agent 不能直接写入 Vault。
- 本地知识检索无结果时，`research:answer-vault` 会以“无本地证据”正常结束，并携带受限的运行反馈自动触发一次替代计划；规划器不得再次选择同一查询动作。替代计划中的联网、打开笔记或写入仍要逐步确认。
- 双层 Agent 记忆：用户画像保存在可直接编辑的 `Agent Profile.md`；用户确认创建会话后，本次问答、运行计划和工具摘要会追加到同一份 `Sessions/*.md`。画像更新始终预览确认，会话与画像默认不进入全局知识索引；敏感目录会阻断其向模型外发。
- PDF/图片增量索引：扫描授权目录后，PDF 经 GLM-OCR、图片经 GLM 视觉模型解析；支持可恢复批处理、暂停/恢复、请求限速与每日次数/上传体积预算。仅缓存可重建的文本摘要，附件变更时才重新入队。
- 按需知识回顾：直接对 Agent 说“复盘/回顾/巩固某主题”；它复用来源问答，给出知识脉络、易混淆点或知识缺口、可点击的关联笔记和下一步，不维护固定间隔、关键词队列或题卡。
- 联网问答：Tavily 只接收用户输入的问题并返回网页摘要；DeepSeek 基于摘要直接输出中文回答。侧栏不展示网页链接，网页来源仅在内部用于写入溯源。
- 联网兜底：Tavily 成功但没有可用网页摘要时，默认仅对稳定知识使用 DeepSeek 通用回答；包含最新、价格、新闻、政策等实时倾向的问题不会自动降级。通用回答会明确标识，且不能自动追加或作为联网结果写入。
- 外部请求去重：重复点击同一问答、联网检索、笔记提案、附件处理或连通性测试时，会复用进行中的请求，避免重复调用和重复扣费。
- 分层保真粘贴：通过命令将 Excel/TSV、HTML 或 Markdown 表格本地转换为规范 Markdown，并在插入前显示质量报告和预览；检测到合并单元格时同时提供安全 HTML 保真版本。仅当用户主动选择“Agent 修复选中内容”时，才会在外发权限允许下将选区发送给 DeepSeek，且模型只能返回格式修复建议。
- 可选自动追加：用户可单独开启“联网搜索后自动追加主题 Daily”；每次成功联网问答会通过同一权限、审计与冲突检测管线追加回答到 `daily/<搜索主题>.md`。

## 本地开发

需要 Node.js 20 或更高版本。

```powershell
npm.cmd install
npm.cmd run build
```

开发时监听构建：

```powershell
npm.cmd run dev
```

将 `main.js`、`manifest.json` 和 `styles.css` 复制到测试 Vault 的下列目录后，在 Obsidian 中启用该社区插件：

```text
<vault>/.obsidian/plugins/knowledge-loop-agent/
```

首次启用后，插件会在该目录创建 `.env` 模板。填写下列所需密钥，回到插件设置点击“重新加载 .env”：

```env
DEEPSEEK_API_KEY=你的DeepSeek密钥
GLM_API_KEY=你的GLM密钥
TAVILY_API_KEY=你的Tavily密钥
```

文本问答与笔记提案需要 DeepSeek；PDF/图片索引需要 GLM；联网问答同时需要 Tavily 和 DeepSeek。两个模型的连通性测试只发送固定文本 `connection-ok`，不会读取或发送笔记、PDF、图片。

### Agent 记忆使用

1. 打开右侧 Agent 对话，在底部输入框直接描述目标。首次发送时会用目标生成会话标题；确认创建后，会话笔记保存在 `00 Inbox/Agent/Sessions/`（可在设置中修改）。
2. Agent 会在对话中给出最多四步的计划；点击“执行下一步”或“确认并执行”推进。涉及外部请求、打开笔记和写入预览的步骤仍需要确认。
3. 本地问答、联网问答、运行计划和工具结果都会追加到同一份会话笔记；顶部选择框可切回已有会话，“结束”会停止继续追加。
4. 顶部“画像”用于创建或打开长期记忆；“记住”才会让 DeepSeek 根据当前会话生成画像更新预览，仍需确认写入。
4. 会话与画像不会被纳入全局知识检索；若将 Agent 记忆目录设为敏感目录，它们仍可本地保存，但不会发送给模型。

## 隐私与安全状态

- API Key 持久保存在插件本地 `.env`，运行时读取到内存；`.env` 已被 Git 忽略，切勿提交或分享。
- 初始权限覆盖整个 Vault，便于个人本地使用；可在设置中收窄目录范围。填写“敏感目录”后，该目录内容始终禁止发送给 DeepSeek 和 GLM。
- 联网问答只外发用户当前输入的问题给 Tavily；它不会上传 Vault 内容。Tavily 返回的网页摘要会发送给 DeepSeek 以生成直接回答。回答默认只存在于当前插件会话内；若用户已确认创建 Agent 会话，则会本地追加到该会话笔记。网页来源不在侧栏展示。
- 自动追加默认关闭；开启后会检查当前“联网搜索”和“允许追加主题 Daily”权限。写入会记录审计事件，且不会覆盖预览后发生变化的文件。
- 后续自动化继续遵循用户可控目录、敏感目录外发阻断、最小外发、结构化行动提案、来源追踪和可撤销写入原则。
